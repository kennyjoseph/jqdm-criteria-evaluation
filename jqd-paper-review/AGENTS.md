# jqd-paper-review

Purpose: give input (an evaluation on 16 criteria, no decision) on a full manuscript for the Journal of Quantitative Description: Digital Media.
Start: read `SKILL.md` in this folder, then run `python scripts/review.py init --manuscript FILE [--loi FILE] [--appendix FILE]`.
Then run the command printed after `NEXT COMMAND:` until the script says the run is complete.
